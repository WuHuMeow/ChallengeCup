# Deliverables Area

This directory is reserved for submission-facing artifacts when they exist.
It is intentionally empty today: this README is the only retained file and no
deliverable is created or implied by this placeholder.

Generated files placed here remain ignored by Git. Add a specific, reviewed
tracking rule only when an actual submission artifact is ready to be retained.

## Minimal Usage

Generate or place a reviewed submission artifact under `output/deliverables/`,
then add a narrow Git tracking exception for that specific file before it is
committed. Do not add the whole generated directory tree.

## Dependencies and Limits

This area follows the ownership and cleanup rules in `output/README.md` and the
repository's Git ignore rules. Until a concrete deliverable and tracking
exception are reviewed, this README remains the only retained file here.
